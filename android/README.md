# Android-версия There Is Time?

Проект `android/` — нативная оболочка Android с локальной WebView-версией игры. Минимальная версия — Android 10 (API 29), целевая — Android 16 (API 36). Файлы игры и доступная озвучка упаковываются в APK при сборке; интернет-разрешение приложению не требуется.

## Как собрать APK

1. Установить актуальную Android Studio, JDK 17 и Android SDK Platform 36 через SDK Manager. При первом запуске Gradle нужны интернет и доступ к Google Maven и Gradle distributions.
2. Открыть **папку `android`** в Android Studio и дождаться Gradle Sync. При необходимости указать путь к Android SDK в настройках Android Studio.
3. В меню выбрать **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Debug APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
4. Установить APK на телефон Android 10–16 или запустить приложение через Android Studio на подключённом устройстве / эмуляторе. Для публикации нужна собственная release-подпись.

В терминале вместо пункта 3 можно запустить из папки `android`: `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).

## Поведение

- Сохранения и настройки остаются на устройстве в WebView. Они отдельные от сохранения браузерного превью; удаление приложения удаляет локальный прогресс.
- Нативная кнопка «Назад» закрывает настройки/заставку, а из истории возвращает в меню. Перед выходом из приложения запрашивается подтверждение.
- Музыка и озвучка приостанавливаются, когда приложение уходит в фон. Нажатие «♫ Звук» повторяет текущую озвученную реплику.
- Права доступа в интернет и к файлам пользователя не запрашиваются. Игра обслуживается только из вложенных файлов через локальный HTTPS-адрес, не совершая сетевых запросов.
- Аудио и история пока неполные: озвучены 170 из 341 текстовой сцены, а прохождение короче изначальной цели 2,5 часа.

APK и совместимость на устройствах здесь не проверены: сборка требует установленного Android SDK и JDK.
